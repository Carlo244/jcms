02

AI-Powered Triathlon Training Coach

Built an Android app that consolidates swim, bike, and run workout data with intelligent AI coaching recommendations using Google Gemini.

Problem

Triathletes track workouts across multiple platforms and struggle to get cohesive, personalized coaching insights—training data sits isolated without actionable guidance.

Approach

Integrated Health Connect API to read exercise sessions, heart rate, and distance data. Engineered system prompts and context formatting to send training metrics to Google Gemini for personalized coaching.

Engineering

Architected MVVM pattern with Jetpack Compose UI, StateFlow for reactive state management, and DataStore for encrypted local persistence of training goals and preferences.

Deployment

Integrated Retrofit for API calls, Firebase for secure Gemini API access, and Material3 design system for polished Android UI across multiple screen sizes.
